# Kho ảnh + video Dream Labs để đăng bài

Lấy từ web dreamlabs.vn (bản hoàn thiện). Ảnh đã đổi sang JPG (Instagram/Facebook/TikTok/Zalo nhận được).

| Thư mục | Nội dung |
|---|---|
| 1-tu-dong-hoa-ai | Ảnh bìa 6 mẫu quy trình AI |
| 2-website | Ảnh bìa + ảnh chụp cả trang (`-long`: máy tính, `-long-m`: điện thoại) |
| 3-landing-page | Như trên cho landing page |
| 4-thiet-ke-san-pham | Bao bì/sản phẩm 3D: từng màu, bộ sưu tập (`-set`), hộp (`-box`), cận cảnh (`-detail`) |
| 5-motion-graphic | 7 phim motion (.mp4) + ảnh bìa |
| 6-edit-video | 6 phim (.mp4) + ảnh bìa + ảnh `-before` (trước khi dựng) |
| 7-video-quang-cao | Quảng cáo 9:16 (21s) + showreel (21s) |

Khung video: 720×1280 (dọc, hợp Reels/TikTok), 1280×720 (ngang, hợp Facebook), 900×900 (vuông).

Lưu ý khi đăng: đây là mẫu concept do Dream Labs tự làm, tên thương hiệu là tên giả lập; ghi "concept" trong bài, không giới thiệu như khách hàng thật.
